Visual chatGPT Studio 

Описание 💬
Visual chatGPT Studio - это мощное расширение, которое интегрирует расширенные возможности искусственного интеллекта непосредственно в Visual Studio, улучшая качество программирования. Это расширение предоставляет набор инструментов, которые используют искусственный интеллект для решения различных задач программирования.

С Visual chatGPT Studio вы можете получать интеллектуальные предложения по коду, создавать модульные тесты, находить ошибки, оптимизировать код и многое другое — все это из вашей среды разработки. Расширение позволяет взаимодействовать с ИИ таким образом, чтобы упростить рабочий процесс, делая написание кода более эффективным и приятным.

Функциональность Copilot (только для Visual Studio 2022) 🤖
Функциональность Copilot расширяет возможности программирования, предоставляя интеллектуальные подсказки по коду при вводе.

Когда вы начнете писать код, просто нажмите клавишу Enter, чтобы получить контекстные подсказки, которые помогут вам более эффективно завершить написание кода. Подтвердите предложение, нажав клавишу TAB.

Возможности редактора кода 👩💻

Пояснить: Напишите объяснение выбранного кода.
Добавить комментарии: Добавьте комментарии к выбранному коду.
Добавить сводку: Добавьте сводку для методов C#.
Добавить сводку для всего класса: Добавьте сводку для всего класса C# (для методов, свойств, перечислений, интерфейсов, классов и т.д.). Не нужно выбирать код, достаточно запустить команду, чтобы запустить процесс.
Задайте любой вопрос: напишите вопрос в редакторе кода и дождитесь ответа.
Перевести: замените выделенный текст переведенной версией. В окне Настроек отредактируйте команду, если вы хотите перевести на другой язык вместо английского.
Пользовательский перед: Создайте пользовательскую команду с помощью параметров, которые вставляют ответ перед выбранным кодом.
Пользовательский после: Создайте пользовательскую команду с помощью параметров, которая вставляет ответ после выбранного кода.
Пользовательская замена: Создайте пользовательскую команду с помощью параметров, которые заменяют выделенный текст ответом.
Отмена: отмените получение/ожидание любых командных запросов.
И если вы хотите, чтобы ответы записывались в окне инструментов, а не в редакторе кода, нажмите и удерживайте клавишу SHIFT и выберите команду (не используйте сочетания клавиш).


Отредактируйте команды 📐
Предварительно определенные команды можно редактировать по своему усмотрению в соответствии с вашими потребностями и потребностями проекта, над которым вы в данный момент работаете.

Также можно определить конкретные команды для каждого решения или проекта. Если вы не работаете над проектом, для которого предусмотрены специальные команды, будут использоваться команды по умолчанию.

Несколько примеров того, что вы можете сделать:

Определите конкретный фреймворк или язык: например, у вас могут быть определенные команды для создания модульных тестов, используя MSTests для одного проекта и xUnit для другого.
Работа на другом языке: Например, если вы работаете в проектах, в которых используется другой язык, отличный от вашего родного, вы можете задать команды для своего языка и команды на другом языке для других проектов.
и т.д.

Важные соображения

Строка подключения никогда не передается в искусственный интеллект. Доступны только имя сервера, имя базы данных и схема.
Данные запроса никогда не отправляются в ИИ, как по соображениям защиты данных, так и для экономии использования токенов. Единственным исключением является выполнение ИИ скалярного сценария (возвращающего только одну запись и один столбец).

Сервисный агент API 🧙♂️
Агент на базе искусственного интеллекта, способный взаимодействовать с большинством сервисов REST и SOAP. Он динамически обрабатывает структуры API, обеспечивая бесперебойную связь с различными веб-сервисами, при этом пользователь может безопасно управлять данными аутентификации.

Выполните следующие действия, чтобы максимально использовать эту функцию:

Добавьте определения API
В окне параметров расширения добавьте определения к нужным API-интерфейсам:

изображение __12.png

Идентификация: Введите уникальное имя для идентификации API.
Базовый URL: Введите базовый URL-адрес API.
Ключ/значения: Определите пары ключ-значение, которые будут включены в запросы API, или замените ключ/значения, определенные AI. Идеально подходит для вставки ключа/значений аутентификации/авторизации или для обеспечения того, чтобы все вызовы имели определенный ключ/значение.
Отправлять ответы ИИ: Если этот флажок установлен, все ответы API будут перенаправляться ИИ, чтобы он мог обработать их и сохранить в своем контексте. В противном случае ИИ будет получать только статус HTTP, а ответы будут отображаться непосредственно в чате. Этот вариант идеален, если вы хотите защитить данные и сохранить токены.
Определение: Введите здесь определение API (например, OpenAPI, Swagger, SOAP). Это позволяет ИИ понять структуру API и возможности для выполнения запросов.

Важные соображения
ИИ никогда не знает о ключах/значениях, настроенных с помощью опций, поэтому они идеально подходят для токенов аутентификации.
ИИ никогда не знает о базовом URL-адресе.
Однако, если по какой-либо причине вы хотите, чтобы ИИ знал вышеуказанные данные, вам придется сообщить об этом ИИ с помощью запросов.
